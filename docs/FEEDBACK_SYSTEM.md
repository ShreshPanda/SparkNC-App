# SparkNC Feedback System

## Purpose
The Feedback System collects structured input from students and ambassadors so the platform can continuously improve while keeping data private and role-scoped.

## Components
- `StudentFeedbackRepository` — D1 access for `student_feedback`.
- `StudentFeedbackService` — validates and submits feedback, computes sentiment.
- `AmbassadorFeedbackRepository` — D1 access for `ambassador_feedback`.
- `AmbassadorFeedbackService` — validates ambassador observations and suggestions.
- `FeatureRequestRepository` / `FeatureRequestService` — community improvement board.
- `FeedbackAnalysisService` — derives `feedback_insights` from feedback and activity.

## Tables
- `student_feedback` — `id`, `user_id`, `category`, `rating`, `feedback_text`, `sentiment`, `created_at`.
- `ambassador_feedback` — `id`, `ambassador_id`, `student_id`, `category`, `observation`, `suggested_improvement`, `created_at`.
- `feature_requests` — `id`, `created_by`, `title`, `description`, `category`, `votes`, `status`, `created_at`.
- `feedback_insights` — persisted insights generated by the analysis service.

## Endpoints
- `POST /feedback` — submit student feedback.
- `GET /feedback` — list current user's feedback.
- `GET /feedback/all` — list recent feedback.
- `POST /feedback/analyze` — generate organization insights.
- `GET /feedback/insights` — list generated insights.
- `POST /ambassador/feedback` — submit ambassador observation.
- `GET /ambassador/feedback` — list ambassador's observations.
- `POST /feature-requests` — create feature request.
- `GET /feature-requests` — list requests (optional `?status=` filter).
- `POST /feature-requests/:id/vote` — up-vote a request.
- `POST /feature-requests/:id/status` — admin update status.

## Sentiment
Simple rule-based analysis from `rating` and keyword scanning. Categories:
- `positive`
- `neutral`
- `needs_support`

No psychological profiling is performed.

## Privacy
- Students only access their own feedback.
- Ambassadors only access observations they submitted.
- Admins can view aggregate insights and feature request board.
